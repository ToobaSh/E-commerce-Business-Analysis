# E-Commerce Business Analysis

## Project Overview

This project explores an e-commerce dataset to better understand:
- customer behavior,
- marketing performance,
- product performance,
- conversion behavior,
- and business opportunities.

The analysis was performed using Python and focuses on transforming raw business data into actionable insights and recommendations.

---

## Datasets Used

The project combines 5 interconnected datasets:

- Campaigns
- Customers
- Events
- Products
- Transactions

These datasets were connected using:
- `customer_id`
- `product_id`
- `campaign_id`

---

## Main Analysis Performed

- Data cleaning and quality analysis
- Missing value investigation
- Revenue and KPI analysis
- Product category analysis
- Customer acquisition analysis
- Loyalty tier analysis
- Conversion funnel analysis
- Device and traffic source analysis
- A/B testing analysis
- Business recommendations

---

## Key Insights

- Electronics is the strongest revenue-generating category.
- Email traffic shows the highest purchase conversion rate.
- Organic traffic generates high revenue volume but lower conversion efficiency.
- Gold and Platinum customers purchase more frequently.
- Variant_B achieved the best conversion performance.
- Around 10% of transactions appear incomplete and may indicate tracking or checkout issues.
